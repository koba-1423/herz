# 公開とユーザーを増やすための計画

Herz は、ただ公開しただけでは誰にも見つけてもらえない。
Apple の返事（ケース 103016127596）を待つ間に、公開の準備とブランドづくりを進め、
公開の日から人が集まり、使った人が次の人を連れてくる形にしておく。

## ブランド

| 項目 | 決めたこと |
| --- | --- |
| 名前 | Herz（ヘルツ）。ドイツ語で「心」、音の単位 Hz とも重なる |
| 一言 | 気分の色で、曲を選ぶ。 |
| 何をするものか | 気分を言葉で書くか、好きな曲やそのリンクを入れると、雰囲気の近い曲が見つかる |
| ロゴ | 太字の「Herz」の文字と、気分の色の丸（`src/herz/web/favicon.svg`） |
| 色 | 白に近いグレーの地に、気分ごとの色。上に細く引いた色の線が目印 |
| 文字 | Apple と同じ書体（San Francisco・ヒラギノ角ゴ） |
| 言葉づかい | 短く、やさしい日本語。専門用語（埋め込み・ベクトル等）は画面に出さない |

### ジャケット写真と試聴は宣伝に使わない

Apple の規約では、ジャケット写真や試聴は「その曲の宣伝」にしか使えない。
Herz そのものの宣伝（SNSの投稿・動画・広告・紹介ページの画像）には使わず、気分の色と文字だけで見せる。
画面を録画するときは、ジャケット写真が映らない「雰囲気で探す」画面を使う。

## 段階ごとにやること

### 0. Apple の返事を待つ間（iTunes のデータを使わないことだけ）

- [x] プライバシーポリシーと外部送信の表示（`/privacy.html`）
- [x] Herz について・運営者情報・お問い合わせ（`/about.html`）。【】の所は決めてから埋める
- [x] ファビコンと、SNSで共有したときの画像（`/og.png`）
- [ ] ドメイン herz.fm を取る（ほかに空いていそうなもの: herz.audio、herz.music、getherz.com）
- [ ] X・Instagram・TikTok のアカウント名を押さえる。X は `herzfm` に決めた（`brand/x-profile.md`）。他も同じ名前で揃える
- [ ] 連絡用のメールアドレスを作る（個人のアドレスと分ける）
- [ ] 事前登録のページを公開する。気分の色と「Herz」の文字だけのページで、公開を知らせるメールアドレスを集める
- [ ] 作っている過程を X に書く（どうやって音で雰囲気を比べているか、22万曲を解析した話など）

### 1. 公開のとき

- [ ] 検索結果を共有できるようにする。`/?q=雨の日に聴きたい静かなピアノ` のようなURLで同じ結果が開き、
      共有したときの画像には気分の色と言葉が出る。使った人が次の人を連れてくる、いちばん大事な仕組み
- [ ] 気分ごとの読み物のページを作る（「雨の日に聴きたい曲」「作業に集中できる曲」など）。
      Google の検索から人が来る入口になり、AdSense の審査に要る文章にもなる
- [ ] アクセス解析を入れる（Cookie を使わない Cloudflare Web Analytics など）。入れたら外部送信の表に足す
- [ ] 公開を知らせる: 事前登録した人へのメール、X、note・Zenn に作った話の記事、はてなブックマーク

### 2. 公開のあと

- [ ] 見つけた曲を Apple Music のプレイリストに保存できるようにする（MusicKit）。アフィリエイトの入口にもなる
- [ ] 「今日の気分」を毎日1つ出して、X でも同じものを投稿する
- [ ] 広告（AdSense の審査が通ってから。ジャケット写真と試聴から離れた場所に置く）
