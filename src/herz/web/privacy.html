プライバシーポリシー

制定日：【公開日】

Herz（以下「本サービス」）の運営者（以下「運営者」）は、本サービスで扱う情報を、次のとおり取り扱います。

1. 扱う情報

入力した言葉と曲

検索欄に書いた言葉や貼った曲のURL、似た曲を探すときに選んだ曲、好みの分析に使う好きな曲の一覧は、検索のために運営者のサーバーに送られます。

アクセスの記録

サーバーには、アクセスした日時、IPアドレス、ブラウザの種類などが記録されます。

ブラウザの中だけに保存する情報

左の一覧（探したもの・名前の変更）と好きな曲の一覧は、お使いのブラウザ（localStorage）に保存します。この保存そのものは運営者のサーバーには送られず、ブラウザのサイトデータを消すと消えます。

本サービスには会員登録がなく、氏名やメールアドレスを入力していただくことはありません。

2. 使う目的

  • 検索や好みの分析の結果を返すため
  • 不正な利用を防ぎ、障害を調べるため
  • 本サービスを改善するため（個人を特定しない形の集計に限ります）

3. 外部のサービスに送られる情報

電気通信事業法の外部送信規律にもとづき、本サービスを使うときに外部のサービスへ送られる情報を公表します。

送り先 Apple Inc.（iTunes）
送られる情報 ジャケット写真の表示や試聴の再生のときに、お使いのブラウザから IPアドレス、ブラウザの種類、閲覧中のページのURL。曲名で探したときは、その言葉が運営者のサーバーから iTunes Search API に送られます
目的 曲の情報、ジャケット写真、30秒の試聴を表示するため
送り先の方針 Apple のプライバシーポリシー
送り先 Spotify AB、Google LLC（YouTube）
送られる情報 Spotify や YouTube の曲のURLを貼ったときに、そのURL（運営者のサーバーから送ります）
目的 貼られたURLの曲名とアーティスト名を調べるため
送り先の方針 Spotify のプライバシーポリシー、 Google のプライバシーポリシー

アクセス解析や広告を使うようになった場合は、その送り先をこの表に追加します。

4. 第三者への提供

上の外部送信のほか、法令にもとづく場合を除き、集めた情報を第三者に渡すことはありません。

5. 改定

このポリシーを変えるときは、このページでお知らせします。

6. お問い合わせ

このポリシーについてのお問い合わせは、お問い合わせからお願いします。
