## 表示名

Herz｜気分の色で、曲を選ぶ。

## プロフィール文

気分を言葉で書くと、雰囲気の近い曲が見つかる音楽検索を作っています。22万曲の音をAIに聴かせて、「雨の午後」「真夜中の街」みたいな気分で探せるように。公開までの過程をここに書きます。

## 固定する投稿

```
「雨の日に聴きたい、静かなピアノ」

こう書くだけで、雰囲気の近い曲が見つかる音楽検索を作っています。

曲名もジャンルも知らなくていい。
22万曲の音をAIに聴かせて、気分の言葉と音を同じものさしで比べています。

名前は Herz（ヘルツ）。もうすぐ公開します。
```

画像は `src/herz/web/og.png` を付ける。

## 最初の投稿の案

ジャケット写真と試聴は Apple の規約で Herz の宣伝に使えないので、画像は気分の色と文字だけにする。

### 1. なぜ作ったか

```
好きな曲を人に説明するとき、
「なんか夜っぽくて、ちょっと切ない感じ」って言いませんか。

その「感じ」のまま曲を探せたらいいのに、と思って Herz を作り始めました。
```

### 2. しくみ

```
Herz は歌詞やタグではなく、曲の音そのものを聴いて比べています。

22万曲の試聴をAIに聴かせて、音の雰囲気を数字の並びに。
書いた言葉も同じ並びに置き換えて、近い順に並べるだけ。

だから知らないアーティストの曲にも出会えます。
```

### 3. 気分の色

```
Herz では、気分ごとに画面の色が変わります。

雨の午後は青、真夜中の街は紫、燃える夜は赤。

あなたの今の気分は何色ですか？
```

画像は検索画面の、気分の色で塗られた部分だけを切り抜いたもの（曲の一覧やジャケット写真は映さない）。

### 4. 聞いてみる

```
「〇〇な気分のときに聴きたい曲」の〇〇、何を入れますか？

返信でもらった気分で、Herz で探した結果を曲名で返します。
```

返すときも曲名とアーティスト名の文字だけにする。

## 登録のときの注意

- 連絡用のメールアドレス（個人のものと分けたもの）で登録する
- アカウントの種類はあとで「プロアカウント」に切り替えると、見られた数などの分析が見られる
